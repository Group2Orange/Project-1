# TeamSpace HR flow guide

Open `project-flow-guide/index.html` through Live Server to explore the project’s current behavior. The guide is a read-only simulation: it never calls the API or changes localStorage. Select a flow in the left navigation, then use **Next step**, **Previous**, or the step labels. Each step shows the trigger, result, relevant code, source file, and an illustrated state.

The guide covers setup, login, first-time password changes, role navigation, profile and details, employee tasks, leave, helpdesk, feedback, the HR employee directory, HR policies, the HR feedback inbox, HR workspace, and logout. It explicitly marks localStorage-only flows and HR screens whose JavaScript files are currently empty.

The source links point to files in this repository. The guide reflects the code at the time it was written; when a flow changes, update the matching entry in `app.js`.
